# Alfa Consultoria — site institucional (React + Vite)

    npm install
    npm run dev      # desenvolvimento
    npm run build    # produção (pasta dist)

- Cores: `src/styles.css`, bloco `:root` (extraídas da logo).
- Logo: `src/logo-mark.png` (símbolo) e `public/logo-completa.png`.
- Contato (WhatsApp/e-mail) e textos dos serviços/etapas: `src/data.js`.
